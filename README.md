# Python製ブラックジャック（コンソール版）

このプロジェクトは、標準入力を受け取りコンソール上で動作するPython製ブラックジャックアプリです。  
教育資料用に作成しています。  

ソースを読んだり実行するだけでは物足りない方は、[Wiki](../../wiki)を見てみてください。  
訓練校では教えてもらえない、少し難しいながら実用的な内容を解説しています。  

## 実行方法

```sh
python main.py
```

## 概要
- プレイヤーとディーラーで対戦するシンプルなブラックジャック
- 標準入力で操作

## 必要要件
- Python 3.x（3.13.5で確認済み）
